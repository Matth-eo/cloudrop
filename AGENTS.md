# AGENTS.md

## Project
Cloudrop is a learning-focused AWS file-sharing project built with Next.js and TypeScript.

## Rules
- Make small, incremental changes.
- Do not build the entire project in one step.
- Explain major architectural changes before implementing them.
- Use TypeScript.
- Use the Next.js App Router.
- Keep components modular and readable.
- Do not add AWS services unless explicitly requested.
- Never expose AWS credentials or secrets in source code.
- Do not commit `.env` files.
- Prefer simple implementations while I am learning.
- Run lint after meaningful changes.
